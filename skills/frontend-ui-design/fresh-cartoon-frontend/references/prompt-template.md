# Reusable prompt template

Use this when a standalone prompt is preferable to installing the skill.

```text
请为这个前端项目设计并实现一种“清新、可信、带一点卡通温度”的产品视觉语言。

先检查现有代码、技术栈、页面结构、组件库、数据流和截图，再修改。保留全部业务功能，不用虚构数据填满界面。

视觉方向：
- 雾白或极浅青背景，深蓝绿色正文，克制的青绿色主色；暖黄或珊瑚色只作为小面积强调。
- 标题圆润、有亲和力但不过度幼稚；正文清楚、稳重、易读。
- 使用统一容器、明确网格、固定控件高度和一致的间距系统，保证标签、输入框、帮助文字及重复卡片严格对齐。
- 控件、卡片、主要面板采用分级圆角；优先用细边框建立层级，阴影柔和且克制。
- 只使用一个连贯的卡通视觉世界，例如纸雕地图、轻黏土或绘本插画。插画服务于内容，不遮挡操作，也不要堆砌 emoji、贴纸和无意义装饰。
- 页面要有一个清晰焦点，不要把所有内容都做成同等权重的卡片，也不要套娃式卡片。
- 交互动画只用于悬停、选中、加载和状态变化，并支持 prefers-reduced-motion。

表单要像一段被引导的流程：相关字段成组，必填信息与偏好信息有明显层级，提示文字紧跟对应字段。结果页先展示总结与关键数字，再展示流程、路线或时间线，最后放详细信息。

需要覆盖宽屏桌面、小尺寸笔记本、平板和手机。特别检查中文长文案、日期输入、金额、错误提示和选中状态是否造成错位。

实现完成后运行项目的类型检查和生产构建；如果可以查看页面，再逐个尺寸检查视觉对齐。不要只给设计说明，直接完成代码并报告修改文件与验证结果。
```
